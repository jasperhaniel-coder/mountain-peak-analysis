# Mountain Peak Analysis Project

This project is a SQL-based data analysis assignment focused on a fictional outdoor retail company called Mountain Peak Outfitters. The main goal is to practice writing SQL queries to explore product performance, customer behavior, inventory levels, employee sales, and store operations. It also helped me learn how to use joins, aggregations, filtering, grouping, and more advanced SQL logic to answer real business questions.

I created this project to strengthen my understanding of relational databases and to apply SQL in a realistic business setting. The dataset includes information about products, suppliers, categories, customers, reviews, employees, transactions, and stores.

## Project Overview

The analysis is designed to answer questions such as:

- Which products are out of stock or running low on inventory?
- Which stores are performing best in sales?
- What are the most popular product categories?
- Which customers spend the most and how often do they buy?
- How do loyalty tiers relate to purchase behavior and ratings?
- Which employees are generating the most sales?
- Are there missing or incomplete product relationships in the data?

By using SQL, I was able to pull useful insights from the data and summarize the results in a clear business-friendly format.

## Folder Structure

- `queries/basic_analysis.sql` – basic SQL queries for product, store, and sales review
- `queries/aggregation_analysis.sql` – grouped summaries and totals
- `queries/advanced_analysis.sql` – more advanced analysis using filters and comparisons
- `queries/relationship_analysis.sql` – joins and relationship-based questions
- `queries/complex_analysis.sql` – more detailed business logic and multi-step analysis
- `findings.md` – summary of the main results and conclusions
- `Setup & Questions/` – assignment setup materials and questions for the project

## What I Learned

This project helped me practice several important SQL skills:

- Writing SELECT statements with filters and sorting
- Using JOINs to connect related tables
- Applying GROUP BY and aggregate functions like SUM, AVG, COUNT, and MAX
- Using CASE statements and conditional logic
- Handling null values and incomplete data
- Comparing business results across stores, products, and customer groups
- Writing cleaner SQL queries that can be reused for reporting

## How to Use This Project

1. Open your SQL editor or database client (for example, MySQL Workbench, SQL Server Management Studio, pgAdmin, or another tool you are using for class).
2. Make sure the database or schema for the assignment is loaded and connected.
3. Open the files in the `queries` folder in the order listed above.
4. Run each query one at a time and review the output.
5. Compare the results with the summary in `findings.md`.
6. If needed, refer to the assignment files in `Setup & Questions/` for the exact task requirements.

## Notes

This project is meant to show how SQL can be used to answer business questions from a database. The results in `findings.md` are based on the sample data provided for the assignment, so they are useful for understanding patterns but should not be treated as real company data.

It was a good learning exercise because it combined database logic with practical business interpretation. I had to not only write the queries correctly, but also understand what the results meant in a real-world context.
